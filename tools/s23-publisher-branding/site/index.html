Privacidad

Herramienta personal · Uso privado

Del teléfono a tu Drive.

MESTRY S23 Publisher publica versiones de un documento de trabajo desde Horus en un Samsung S23 a una carpeta privada de Google Drive, para revisarlas desde otro dispositivo.

Cómo se utilizan los datos ↗

01 · Publicación

Versiones conservadas

El publicador comprueba el contenido y crea una nueva versión cuando cambia. No sobrescribe las versiones publicadas ni hace públicos los documentos.

02 · Permiso

Acceso limitado

Solicita únicamente drive.file: acceso a archivos creados o autorizados para la aplicación. No solicita acceso general a toda la unidad.

Una integración personal

El piloto actual publica un documento Markdown de prueba, limitado a 64 KiB. La autorización se completa en el navegador del propietario y el publicador conserva las credenciales en el entorno privado de Termux del S23.

Esta web es informativa: no inicia sesiones, recibe documentos ni solicita credenciales. No es un servicio público de almacenamiento ni un producto de Google.
