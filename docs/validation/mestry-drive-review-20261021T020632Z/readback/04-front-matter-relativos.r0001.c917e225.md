# Front matter y finales de línea

Este archivo se guarda inicialmente con finales CRLF para comprobar si una apertura sin edición conserva los bytes.

[Enlace relativo de prueba](./archivo-relativo-no-publicado.md)

![Imagen relativa de prueba](./imagen-relativa-no-publicada.png)

Los destinos relativos no se publicaron. Esta prueba no promete que Drive resuelva enlaces relativos de un repositorio.

Después de una edición humana, se debe comparar el cambio y conservarlo como propuesta; no exigir el hash original ni sobrescribirlo.
